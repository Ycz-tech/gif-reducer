# GIF 压缩器

原生 macOS 工具：将视频转为 GIF，或把已有 GIF 压得更小。支持批量处理和 Finder 右键服务，提供 **19 MB 以内**、**9.8 MB 以内**两档目标。

当前分享版本：**v1.3.3（Build 8）**。

## 下载与安装

- [下载 App（Apple Silicon）](https://github.com/Ycz-tech/gif-reducer/releases/download/v1.3.3/GIF-Reducer-v1.3.3-macOS-arm64.zip)
- [全部下载与版本说明](https://github.com/Ycz-tech/gif-reducer/releases/tag/v1.3.3)
- [安装说明](安装说明.md)

普通用户下载 App ZIP 即可，无需编译。解压后将 **GIF 压缩器.app** 拖入“应用程序”，再打开。

要求：**Apple Silicon Mac（M 系列）、macOS 14 或更新版本**。本次预编译包不支持 Intel Mac；源码可供自行构建，但尚未在 Intel Mac 验证。

## 当前功能

| 功能 | 行为 |
| --- | --- |
| 视频转 GIF | 输入 MP4、MOV、M4V；具体视频编码须能被解码器读取 |
| GIF 再压缩 | 输入已有 GIF，沿用同一套压缩规则 |
| 两档目标 | 严格小于 19,000,000 或 9,800,000 字节（十进制 MB） |
| 批量处理 | 拖入或选择多个文件，按顺序处理；单个失败不阻断后续任务 |
| 保存位置 | 源文件同目录，或记住自定义文件夹；同名输出自动加序号 |
| 结果与队列 | 显示体积、品质、尺寸和 Finder 入口；成功文件自动移出待处理列表 |
| 失败与取消 | 保留失败或尚未完成的输入以便重试，支持取消 |
| Finder 服务 | 选中文件后右键“服务”，选择 19 MB 或 9.8 MB；沿用 App 保存设置 |
| 时间轴校验 | 按源时间轴采样，编码后验证 GIF 总时长，防止高帧率视频被直接慢放 |

处理在本机进行，不上传视频或 GIF。输出为新文件，不覆盖源文件。

## 压缩规则

先完整编码 **品质 100%、尺寸 100%**，满足目标即保存；超限后依序尝试：

| 顺序 | 固定参数 | 搜索范围 |
| --- | --- | --- |
| 1 | 品质 100% | 尺寸 100% → 70% |
| 2 | 尺寸 70% | 品质 100% → 80% |
| 3 | 品质 80% | 尺寸 70% → 50% |
| 4 | 尺寸 50% | 品质 80% → 60% |
| 5 | 品质 60% | 尺寸 50% → 30% |
| 6 | 尺寸 30% | 品质 60% → 40% |

每段优先保留较大的尺寸或较高的品质；采用大小预测、二分搜索和邻近候选检查，并非穷举所有组合。尺寸表示宽高各自的比例。每个交付结果均按实际字节数验证；若尺寸 30%、品质 40% 仍超限，则提示无法达到目标，不继续降低。

已测参数会缓存，超限候选可提前中止，减少重复编码。处理时间取决于时长、分辨率、内容复杂度、编码器和尝试次数。

## 编码工具

App 不捆绑第三方编码工具。检测到本机 FFmpeg、ffprobe 和 gifski 时优先使用；否则使用 Apple AVFoundation / ImageIO 完成可支持的输入处理。推荐通过已安装的 Homebrew 执行：

```sh
brew install ffmpeg gifski
```

ffprobe 随 FFmpeg 一起安装。不同编码路径的画质、体积和性能可能不同；安装推荐工具更接近开发时的常用环境。

## 播放与功能边界

- GIF 没有音轨；视频音频不会保留。
- 时间轴采用 20 毫秒网格（最高约 50 帧/秒），高帧率输入按时间抽帧，重复画面可能合并，不会保留每一帧。
- GIF 有色彩与时间精度限制，“品质 100%”不代表无损或与视频完全一致。
- 编码后时长偏差超过 20 毫秒时停止输出。Finder 空格快速预览等播放器仍可能按自身调度播放得较慢；文件时长正确不代表每个播放器的实际播放速度一致。
- 当前没有剪辑、片段拼接，也没有“不限制大小转换为 GIF”入口。
- App 使用本地临时签名，未做 Apple Developer ID 签名或公证；首次打开可能需按系统提示在“隐私与安全性”中选择“仍要打开”。

## 源码与构建

完整源码随 Release 的 `gif-reducer-v1.3.3-source.zip` 提供，含 Swift 源文件、测试、Info.plist、图标资源和构建脚本。需要包含 Swift 6.2 或更新版本的 Xcode / Command Line Tools。

在源码目录执行：

```sh
zsh ./构建应用.sh
```

脚本先运行测试，再构建 release，并输出 `dist/GIF 压缩器.app`；已有输出时拒绝覆盖。也可运行 `swift test` 单独测试。

这是源代码公开分享，尚未指定开源许可证。
